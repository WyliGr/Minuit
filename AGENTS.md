# Minuit

Cinema schedule aggregator. Two independent packages (not a workspace monorepo):

- `backend/` — AdonisJS 7 API (TypeScript, SQLite via Lucid, **npm**)
- `frontend/` — Next.js 16 app (**pnpm** — using npm here will break the lockfile)
- `docs/API.md` — API reference; trust it over assumptions about endpoint shapes
- `docker-compose.yml` — production-style deploy (backend on :3333, frontend on :8080 with `/api` rewritten to the backend at build time, Swagger UI on :8088 reading `backend/openapi.yaml`)

## Backend (run inside `backend/`)

- `npm run dev` — dev server with HMR (only `app/controllers/**` and `app/middleware/*` hot-reload; service/model edits need a restart)
- `npm run test` — all Japa tests; suites: `unit`, `functional`
  - single suite: `node ace test unit`
  - single file: `node ace test --files=api.spec.ts`
  - single test title: `node ace test --tests="GET / health check"`
- `npm run lint` / `npm run typecheck` / `npm run format` — run all three before considering work done
- AdonisJS path aliases: imports use `#controllers/*`, `#models/*`, `#services/*`, etc. (see `imports` in package.json) — do not use relative paths across these boundaries
- Tests use `.env.test` (separate `database/minuit.test.sqlite`); functional tests migrate + seed per test via `testUtils.db()` — no external services needed
- Route definitions live in `start/routes.ts`; all public endpoints are under `/api/v1`, no auth

### Gotchas

- `APP_KEY` is required (`config/encryption.ts`); copy `backend/.env.example` to `backend/.env` before dev/test. `.env` files are gitignored.
- `SCHEDULES_TZ=Europe/Paris` drives "today" showtime filtering — time-sensitive logic depends on Paris time, not UTC, even though `TZ=UTC`.
- Poster images are proxied through `GET /api/v1/poster?url=...` to bypass Allociné CDN hotlink/CORS blocks; only `https://` URLs on `*.acsta.net` are allowed (422 otherwise). Don't point the frontend at CDN URLs directly.
- Schedules are cache-first (SQLite cache, `CACHE_TTL_MINUTES`, default 6h) — fresh fetches from Allociné don't happen on every request.

## Frontend (run inside `frontend/`)

- `pnpm dev` / `pnpm build` / `pnpm lint`
- Keep the `nextjs-agent-rules` block in `frontend/AGENTS.md` — it is auto-generated by `next dev` and will re-appear if deleted; commit it to keep the tree clean. It points to docs in `node_modules/next/dist/docs/` for this Next.js version's breaking changes.
